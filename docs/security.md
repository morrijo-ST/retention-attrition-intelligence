# Security — Retention & Attrition Intelligence

- Keep warehouse, BI, and CRM credentials outside source control.
- Protect customer-level recurring-revenue and contract data with least-privilege access.
- Separate public demo data from production data and environments.
- Do not expose real customer names, contract identifiers, renewal dates, or revenue amounts in public artifacts.
- Validate exported screenshots and CSVs before publication.
- Document metric definitions so sensitive data does not need to be copied into analysis notes.
- Restrict any future predictive-risk features to approved attributes and governed use cases.
- Use synthetic customer and contract records for all public demonstrations.
